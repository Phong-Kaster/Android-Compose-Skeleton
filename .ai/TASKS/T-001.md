# T-001 — App posts a "hello world" notification on every cold start

- **Status:** in-progress (code complete; build + runtime verification pending capability activation)

## Description

Add the missing posting side of notifications and wire it to cold start:

- `ui/util/NotificationUtil.kt` — reusable `object` (mirror of `PermissionUtil`): `createChannel(context)` guarded for API 26+ via `NotificationChannelCompat`, and `postSimpleMessage(context, title/message)` using `NotificationCompat.Builder` + `NotificationManagerCompat.notify`. Must check `isNotificationGranted(context)` (existing helper) and silently no-op when not granted — never crash with `SecurityException`.
- Strings appended to end of `strings.xml`: `hello_world`, channel name/description keys.
- Call site: `MainApplication.onCreate()` — runs exactly once per process, which is the cold-start semantics the PRD asks for (warm starts / config changes do not re-run it).
- KDoc with `@author Phong-Kaster` on every new class/function; README package tree updated with the new file.
